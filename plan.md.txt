==================================================
1. PRODUCT OVERVIEW
==================================================

This is a subscription-based multi-tenant SaaS application for doctors and clinics.

The platform allows a Super Admin to create and manage clinics.

Each clinic can have:

- One or multiple doctors
- One or multiple receptionists
- Patients
- Appointments
- Daily patient queues
- Consultations
- Prescriptions
- Billing/payment records
- Patient history
- Reports

The application must support strict tenant isolation.

Clinic A must NEVER be able to access Clinic B's patients, doctors, appointments, consultations or billing data.

22. MULTI-TENANCY SECURITY
==================================================

This is one of the most important requirements.

Every request must establish:

authenticatedUser
role
clinicId

For clinic users:

clinicId comes from the authenticated user's membership.

Never trust:

req.body.clinicId
req.query.clinicId
frontend-selected clinicId

to determine access.

Every database query involving tenant data must enforce clinic ownership.

Example:

DO NOT:

Patient.findUnique({
  where: { id: patientId }
})

without verifying clinic ownership.

Instead ensure the patient belongs to the authenticated clinic.

Never allow:

Clinic A user
→ Clinic B patient
